# RadioButton

## Styling tokens

Override these anywhere in the DOM above the component — `:root`, a
container, or the element's own `style`. Nothing else is needed.

| Token | Falls back to |
|---|---|
| `--dnet-radio-button-background` | `var(--dnet-sys-primary-strong)` |
| `--dnet-radio-button-border-width` | `1px` |
| `--dnet-radio-button-font-size` | `var(--dnet-sys-text-md)` |
| `--dnet-radio-button-size` | `16px` |

```css
:root { --dnet-radio-button-background: /* your value */; }
```
