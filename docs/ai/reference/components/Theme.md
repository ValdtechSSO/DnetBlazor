# Theme

## `<DnetThemeScope>`

```razor
<DnetThemeScope
/>
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `Theme` | `string?` | — | Gets or sets the theme applied to the component subtree. |
| `Class` | `string?` | — | Gets or sets additional CSS classes for the component root. |
| `ChildContent` | `RenderFragment?` | — | Gets or sets the child content rendered by the component. |
